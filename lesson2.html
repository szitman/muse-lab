① 记忆管理未完成

记忆不是玄学：它记了什么，你随时能让它列出来，逐条改、逐条删。先在下面这个模拟清单里练一遍手感。

第一步 · 自述让它把记住的事全列出来——先看见，才谈得上管理。
第二步 · 纠错记错的当场改；过时的当场删。让它改，它就真改；让它忘，它就真忘。
第三步 · 补偏好把回答风格、验收习惯、固定规矩教给它，一次设置，长期生效。
🎯 本节任务：下面这份模拟记忆里，有一条记错了、有一条已经过时。找出来：错的那条点「改一改」更正它，过时的那条点「忘掉」删了它；然后再补上至少一条长期偏好。三件都做完，本模块就算过关。

模拟清单：Muse 记住的关于我的事

补一条长期偏好（点一下就教给它）

Muse（模拟）：你好，这是我记住的关于你的事，一共 4 条。你可以逐条检查。
✅ 记忆体检完成：改对了一条、删掉了一条过时的、还补上了长期偏好。这就是"管记忆"的完整一轮——看见、自述、纠错、删除、补充。
📱 回真 App 跟做：打开你手机上的 Muse，直接对它说"把你记住的关于我的事列出来"，逐条核对；错的就说"我儿子是八年级，不是七年级，改过来"，不要的就说"把那条忘掉"。 另外：以前在别的 AI 那里攒下的偏好不用重教——Settings → Data controls → Import memory 可以把旧 AI 的记忆导进来。

② Settings 权限深挖打磨中

本课的重点：把第一次课讲的"红线意识"，变成一个一个能拨的开关。这一模块正在细细打磨，将包含：

  • 模拟权限树：每个已连接账号的读 / 写动作，逐项练 Allow / Ask / Deny，拨错立刻弹风险说明
  • Background sync 开关演示：开和关，分别会发生什么
  • 旧放行记录（Recipient permissions）撤销练习
  • 全局默认 vs 单项覆盖：最小够用原则的对比演示
  • Browser 五件套与 Secure credentials：新手推荐配置对照
  • 审批卡实操：6 个真实场景，批准还是拒绝，当场反馈

先记住这一句：全局定调子，单项开小灶，旧账随时清。

③ 多步任务链打磨中

聊天 AI 只能做一步，这个助手能把一件事串成链。这一模块将做成步进演示：

  • 读邮件 → 提取事项和截止日期 → 建日历 → 提前一天提醒 → 汇总汇报，一步步点着走完
  • 每一步标注"验收点"在哪里看：日历里能看到、Upcoming 里能看到
  • 出错先查 Activity：哪一步做的、什么时候做的，全有记录

派多步任务的诀窍：把验收点写进指令——"建完日历把事件标题报给我核对"。

④ 自动化诊所打磨中

把你每周都要重复做的一件事，改造成一个定时任务。这一模块将做成填空生成器：

  • 照着模板填空：每＿＿，把＿＿做一遍，结果按＿＿发我；没有变化就不用发；涉及＿＿先问我
  • 一键生成可复制的任务措辞，拿回真 App 就能用
  • 互审清单：权限有没有放大、没变化是否静默、Upcoming 里能不能找到并关掉它

⑤ 作业 2.0 与答疑打磨中

课后作业会原样搬到这里：必做一项（权限审计）＋ 五选二，每一项都能勾选，进度存在你的手机浏览器里，一周内慢慢完成。

  • 必做 · 权限审计：逐个账号过权限树，发送类 = Ask 或 Deny，审计前后各截一张图
  • 五选二：买菜比价官 2.0 / 邮件秘书 2.0 / 英语跟读教练 2.0 / 家庭指挥中心 / 记忆大扫除
  • 答疑 FAQ：记错了怎么办、定时任务半夜吵人怎么办、两个邮箱能分开吗、做的事怎么验
